# Task Tracker

A simple to-do list. Add tasks, tick them off when done, edit them, or delete them.


## Features

- Add a task to the Todo list
- Tick a task's checkbox to move it to Completed Tasks (un-tick to move it back)
- Edit a task's text inline
- Delete any task
- Separate Todo and Completed Tasks sections

## Tech Stack

- HTML
- CSS
- JavaScript

## How to Run

Just open `index.html` in any browser. No build step, no server needed.

```bash
# or serve it locally
python3 -m http.server
# then open http://localhost:8000
```

## Notes

Tasks live only in the page while it is open — there is no save to storage or backend, so refreshing the page clears the list.
